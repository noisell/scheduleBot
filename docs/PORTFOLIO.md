# scheduleBot — мой первый проект

Я разработал Telegram-бота с расписанием пар колледжа за один месяц, начав без опыта программирования. За время работы освоил основные конструкции языка, обработку данных, взаимодействие с Telegram и внешними API, работу с SQLite и асинхронными задачами. Этот проект стал для меня началом профессионального интереса к разработке.

Главная задача заключалась в обработке PDF: базовое расписание и ежедневные изменения публиковались в документах со сложной табличной структурой. Я разработал собственные правила восстановления ячеек, выделения групп, преподавателей и подгрупп, обработки замен, отмен и дополнительных занятий. Затем связал результат с Telegram-интерфейсом и автоматическим отслеживанием обновлений для двух корпусов.

На расписании моего колледжа алгоритм корректно определял пары и без ошибок обрабатывал ежедневные изменения. Для меня это был первый опыт, когда самостоятельный поиск и большое количество экспериментов превратились в полезный продукт.

Сегодня я вижу недостатки структуры кода, но не считаю их главным содержанием этого кейса. Я горжусь тем, что смог с нуля разобраться в задаче, придумать собственное решение и довести его до работающего приложения. Именно во время этой разработки я по-настоящему влюбился в программирование.

## Для резюме

> **scheduleBot — самостоятельная разработка первого проекта за месяц.** Создал Telegram-бота с расписанием колледжа, начиная без опыта программирования. Разработал алгоритм разбора PDF с учётом подгрупп, типов недели, замен и отмен. Реализовал отслеживание обновлений документов для двух корпусов, формирование актуального расписания и уведомления. Стек: Python, aiogram 3, pdfplumber, SQLite, requests, asyncio.

## Короткая карточка

> **scheduleBot · Python / Telegram / PDF parsing**
> Мой первый проект: за месяц с нуля разработал бота, который превращает PDF-расписание колледжа в персональный сервис с ежедневными изменениями и уведомлениями. Главная инженерная работа — собственные правила разбора сложных таблиц и объединения базового расписания с заменами.
